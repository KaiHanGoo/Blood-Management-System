PROCEDURE
1. Show a procedure when the Blood Type is submitted, it will generate the report about the total amount of donated blood per year and the total number of donation per each blood type. This report will display the blood id, blood type, total amount(ml) of donated blood  and total number of donation.

CREATE PROCEDURE GetBloodReport(In Blood_Type varchar(2))
SELECT bloodbank.Blood_ID,bloodbank.Blood_Type, year(donation.date_donate),sum(donation.Donation_Amt) AS 'Total Amount of Donated Blood (ml)',count(donation.donation_ID) AS 'Total Number Of Donation'
FROM donation,bloodbank
WHERE donation.Blood_ID=bloodbank.Blood_ID AND
bloodbank.Blood_Type = Blood_Type
GROUP BY year(donation.date_donate);

By using command: 
call GetBloodReport('A');

2. Show procedure when the Hospital ID is submitted, it will generate the report about the  total amount of recipient of each blood type and total blood request quantity. This report will display the hospital id, hospital name, hospital state, recipient blood type, total amount of recipient of each blood type, total blood request quantity.

CREATE PROCEDURE GetHosReport(IN Hos_ID varchar(5))
SELECT hospital.Hos_ID,hospital.Hos_Name,hospital.Hos_State, recipient.Reci_BloodType,COUNT(recipient.Reci_ID) AS 'Total Amount Of Recipeint',SUM(recipient.Reci_BAmt) AS 'Total Amount Of Blood Used(ml)'
FROM hospital, recipient
WHERE hospital.Hos_ID = recipient.Hos_ID AND
hospital.Hos_ID = Hos_ID
GROUP BY Reci_BloodType;
